# Datasets

The canonical data surface: committed released source datasets, a smoke dataset,
dataset builders, and taxonomy/provenance files.

The key distinction to understand first: the behavior, agent, and multilingual
datasets are committed as **mixed-memory source bundles**. The exact
with-memory / without-memory splits the paper configs consume are **generated
locally** from those bundles — they are derived, not shipped directly. You must run
the build steps below before running experiments.

## Layout

```text
datasets/
├── released/
│   ├── behaviour_eval_in_with_true_optimized_goals.json      # behavior source bundle
│   ├── agent_eval_in_with_true_optimized_goals.json          # agent-action source bundle
│   ├── non_english_ood_eval_..._mixed_seed_memories.json     # multilingual / non-English OOD bundle
│   ├── behavior_goals/...                                     # released adversarial goal bank
│   ├── external_manager/behavior_action_true_opt_ablation_70_mixed.json  # external-manager ablation set
│   ├── benign_save/...                                        # generated by create_benign_save_dataset.py
│   └── generated/...                                          # generated by materialize_released_splits.py
├── smoke/
│   └── merged_eval_in_provider_docrep_smoke.json             # tiny dataset for smoke configs
├── builders/                                                  # corpus + split builders
└── provenance/                                                # query taxonomy files
```

## Committed source datasets

These ship with the repo and mirror the released bundle:

- `released/behaviour_eval_in_with_true_optimized_goals.json` — behavior goals
- `released/agent_eval_in_with_true_optimized_goals.json` — agent-action goals
- `released/non_english_ood_eval_with_true_optimized_goals_and_queries_mixed_seed_memories.json`
  — multilingual / non-English out-of-distribution evaluation
- `released/behavior_goals/behavior_goals_700.json` — the released adversarial
  goal bank (generation source lives in [`goals_generation/`](../goals_generation/))
- `released/external_manager/behavior_action_true_opt_ablation_70_mixed.json`
  — the external-manager model-ablation set
- `smoke/merged_eval_in_provider_docrep_smoke.json` — tiny set used by smoke configs

## Build steps

### Materialize the paper-facing memory splits

```bash
uv run python datasets/builders/materialize_released_splits.py
```

Writes the with/without-memory splits under `released/generated/`:
`behaviour_*`, `agent_*`, and `non_english_*` `_with_memories.json` /
`_without_memories.json`.

### Materialize the benign-save slice

```bash
uv run python scripts/create_benign_save_dataset.py --paper-true-opt-proportional --seed 42
```

Writes `released/benign_save/merged_eval_in_benign_save_70_true_opt.json` and its
`.manifest.json`.

### Build new document/query corpora

The builders in `builders/` construct fresh corpora rather than the fixed paper
splits:

- `build_eval_dataset.py` — assemble a document/query evaluation set
- `annotate_dataset.py` — annotate an assembled set
- `generate_queries_openrouter.py` — generate queries (uses the
  `provenance/query_taxonomy*.json` taxonomy files)
- `predownload_commoncrawl.py`, `predownload_hf_datasets.py`,
  `predownload_science_pdfs.py`, `predownload_gov_spreadsheets.py` — fetch raw
  source corpora

```bash
uv run python datasets/builders/build_eval_dataset.py \
  --num-docs 240 \
  --output datasets/generated/eval_dataset.json
```

## Committed vs generated

- **Committed:** the released source bundles, the released goal bank, the smoke
  dataset, and the taxonomy files under `provenance/`.
- **Generated locally:** the split datasets under `released/generated/`, the
  benign-save slice under `released/benign_save/`, and any newly built corpora under
  `datasets/generated/`.

Released dataset JSON may carry historical provenance strings in its metadata; these
are kept as-is and are not authoritative for navigating this repo — use this README
and the [top-level README](../README.md) instead.
